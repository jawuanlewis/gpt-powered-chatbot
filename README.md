## 🧠 Project Overview

The original source code for my personal AI-powered chatbot, **_Jawuan's GPT_**. This monolithic repo contained both the React frontend and Node.js/Express backend. It has since been migrated into two standalone repositories for better separation of concerns and independent deployment.

## 📦 Current Repositories

| Repository                                                                  | Description                                                    |
| --------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [jawuan-gpt-client](https://github.com/jawuanlewis/jawuan-gpt-client)       | React frontend — UI, chat management, and AI interaction       |
| [jawuan-gpt-api](https://github.com/jawuanlewis/jawuan-gpt-api)             | Express backend — REST API, chat logic, and OpenAI integration |

For setup instructions, tech stack details, and contribution info, please refer to the READMEs in those repositories.
